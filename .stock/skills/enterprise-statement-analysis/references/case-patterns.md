# 常见报表模式与追问路径

这些是分析中反复出现的“模式”，不是造假认定。每个模式都可能有正常商业解释；先提出假设，再用附注、公告、审计意见和同业数据验证。

## 模式 1：高商誉并购

**报表信号**

- 商誉/净资产高（>30%），或商誉增长远快于收入/利润。
- 并购对价高、被并购企业无形资产/固定资产评估增值大。
- 业绩承诺期临近结束，或承诺完成率刚好达标。
- 减值损失在某年集中出现。

**可能解释**

- 买方高预期、战略协同、渠道/技术/品牌价值；
- 卖方高业绩对赌；
- 并购估值过高、商誉是“纸面资产”，不直接推动收入。

**核查**

- 商誉所在资产组、被并购企业实际业绩 vs 承诺；
- 减值测试关键假设（收入增长率、毛利率、折现率）；
- 并购对价、评估增值、可辨认净资产公允价值；
- 并购后收入/利润/现金流是否改善；管理层是否更换。

**结论表述**

“商誉 X 亿元，占净资产 Y%；被并购企业 20XX 年承诺业绩完成率 Z%。若未来增速/毛利率不达减值测试假设，存在减值风险；当前不能仅凭商誉高认定减值已发生。”

## 模式 2：控股股东/关联方资金占用

**报表信号**

- 其他应收款长期高企，增速快于收入；
- 母公司其他应收款远高于合并数；
- 预付款项流向关联方，商业实质存疑；
- 货币资金受限、存贷双高；
- 违规担保、诉讼、监管处罚、审计意见强调事项。

**可能解释**

- 正常保证金、备用金、关联方结算；
- 控股股东/关联方占用上市公司资金；
- 通过供应商/往来单位中转资金。

**核查**

- 其他应收款对象、账龄、坏账准备；
- 关联方交易公告、资金占用专项说明；
- 审计意见/关键审计事项、监管问询/处罚；
- 预付款项的商业实质、供应商背景；
- 资金流水是否与业务匹配（如可得）。

**结论表述**

“其他应收款 X 亿元，占总资产 Y%，其中对关联方 Z 亿元；审计意见/公告显示……。若资金无法收回，将形成资产损失；需区分已披露关联交易与未披露占用。”

## 模式 3：补贴依赖

**报表信号**

- 其他收益/营业利润高（>30%），或连续多年靠其他收益扭亏；
- 其他收益与营业收入/研发/资产购建相关；
- 扣非净利润远低于净利润。

**可能解释**

- 产业政策支持、研发补贴、稳岗补贴；
- 补贴可持续，也可能随政策退出；
- 企业通过补贴维持利润，核心业务盈利能力弱。

**核查**

- 其他收益明细、补贴政策依据、持续年限；
- 扣非净利润、核心利润；
- 补贴与资产/研发/就业的关联；
- 政策变化风险。

**结论表述**

“其他收益 X 亿元，占营业利润 Y%；其中 Z 为持续性研发/产业补贴。若补贴退坡，核心利润需能补足缺口，否则利润将显著下降。”

## 模式 4：投资收益/公允价值变动支撑利润

**报表信号**

- 杂项收益/营业利润高；
- 投资收益主要来自权益法/处置收益/金融资产；
- 公允价值变动收益大且无现金流；
- 核心利润为负或很低。

**可能解释**

- 投资主导型企业，投资回报是主要利润来源；
- 非经常性处置收益；
- 金融资产估值波动，利润“虚”。

**核查**

- 投资收益明细：权益法、处置、股利、金融资产；
- 被投资企业盈利/现金流/分红；
- 公允价值层级、估值假设；
- 核心利润与投资收益的可持续性。

**结论表述**

“营业利润主要由投资收益/公允价值变动贡献，核心利润为 X 亿元；公允价值变动无现金流跟进。若市场价值回落，利润可能逆转。”

## 模式 5：应收账款/合同资产激增

**报表信号**

- 应收增速显著高于收入增速（>20 个百分点）；
- 应收账款/收入上升，周转天数拉长；
- 合同资产大增，项目结算滞后；
- 坏账准备/信用减值损失上升。

**可能解释**

- 放宽信用政策、抢占市场；
- 客户结构变化、回款周期拉长；
- 提前确认收入、关联方赊销；
- 项目制业务正常结算周期。

**核查**

- 账龄、前五大客户、坏账准备政策；
- 合同资产对应项目进度/结算条件；
- 期后回款、坏账核销；
- 收入确认政策、关联交易。

**结论表述**

“应收增速 X%，收入增速 Y%；若回款周期继续拉长，经营现金流将承压。需核查账龄和前五大客户，判断是信用政策还是收入质量问题。”

## 模式 6：存货积压/毛利率下降

**报表信号**

- 存货大增，周转率下降；
- 毛利率下降且周转下降（降价也卖不动）；
- 存货跌价准备不足/集中计提；
- 经营现金流低于核心利润。

**可能解释**

- 需求下降、产品老化、渠道库存高；
- 为未来销售备货（需订单/产能验证）；
- 少转成本/存货积压调节毛利。

**核查**

- 存货构成、库龄、跌价准备；
- 订单/产能/渠道库存；
- 毛利率与周转的多年趋势；
- 期后销售/退货。

**结论表述**

“存货 X 亿元，周转率 Y 次；毛利率下降 Z 个百分点。若需求未改善，存货跌价和现金流压力将上升；需核查库龄和期后销售。”

## 模式 7：在建工程长期不转固/产能过剩

**报表信号**

- 在建工程/固定资产高，且多年不转固；
- 资本开支/经营现金流高，依赖融资；
- 固定资产原值增长快于收入；
- 产能利用率低、折旧压力上升。

**可能解释**

- 项目周期长、建设延期；
- 产能超前布局，等待需求；
- 延迟转固以减少折旧/维持利润；
- 过度投资、产能过剩。

**核查**

- 在建工程明细、预算、进度、转固条件；
- 资本开支与收入/产能的匹配；
- 产能利用率、订单/价格；
- 折旧政策、利息资本化。

**结论表述**

“在建工程 X 亿元，占固定资产 Y%；项目预计 Z 年转固。若收入/产能消化不及预期，折旧和减值将压低未来利润。”

## 模式 8：存贷双高/过度融资

**报表信号**

- 货币资金高，同时有息负债高；
- 利息收入与利息费用同时较大；
- 经营现金流充足仍持续融资；
- 货币资金/短期有息负债高但资金受限。

**可能解释**

- 集团资金集中管理、子公司资金需求；
- 融资成本低、套利/备用授信；
- 资金受限/被占用；
- 过度融资、代理问题。

**核查**

- 受限资金明细、募集资金专户；
- 有息负债期限/利率、融资必要性；
- 利息收入/费用与平均余额的匹配；
- 大股东占用、关联方资金往来。

**结论表述**

“货币资金 X 亿元、有息负债 Y 亿元，存贷双高；若资金受限或融资非经营所需，资金使用效率低，需核查受限资金和融资用途。”

## 模式 9：母子公司利润背离

**报表信号**

- 母公司净利润 > 合并净利润，或母公司盈利/合并亏损；
- 母公司投资收益远高于合并投资收益；
- 少数股东损益为负/正且规模大；
- 子公司亏损、商誉/长期股权投资减值。

**可能解释**

- 子公司整体亏损，拖累集团；
- 子公司向母公司分红，母公司投资收益高；
- 少数股东分担亏损/分享利润；
- 集团内部交易/转移定价。

**核查**

- 母公司/合并利润表、投资收益明细；
- 子公司经营数据、少数股东权益；
- 分红政策、内部交易；
- 商誉/长期股权投资减值。

**结论表述**

“母公司净利润 X 亿元、合并净利润 Y 亿元；差异主要来自子公司亏损/分红。若子公司盈利不能改善，集团整体价值和分红能力将受影响。”

## 模式 10：同一控制下合并/报表拼接

**报表信号**

- 收入/利润/资产在一年内大幅增长；
- 并购发生在年末，但合并了被并购企业全年数据；
- 股本/资本公积大幅增加；
- 被并购企业原为控股股东资产。

**可能解释**

- 同一控制下企业合并，视同年初合并；
- 控股股东注入资产，扩大上市公司规模；
- 需要关注交易对价、股权结构、少数股东利益。

**核查**

- 合并类型、合并日、对价；
- 被并购企业全年数据、业绩承诺；
- 股权结构变化、控制权；
- 评估增值、商誉/资本公积。

**结论表述**

“20XX 年收入/资产大幅增长主要来自同一控制下合并，并非内生增长；需区分内生与外延，关注对价、股权结构和被并购企业质量。”

## 模式 11：审计意见/关键审计事项预警

**报表信号**

- 非标准审计意见（带强调事项段、保留、否定、无法表示）；
- 关键审计事项涉及收入确认、应收账款、存货、商誉、关联方、持续经营；
- 审计机构变更、审计费用异常。

**可能解释**

- 持续经营重大不确定性；
- 资金占用/违规担保/诉讼；
- 收入/资产真实性存疑；
- 审计范围受限。

**核查**

- 审计意见全文、形成基础；
- 关键审计事项及审计程序；
- 监管问询/处罚、诉讼；
- 期后事项、持续经营措施。

**结论表述**

“审计意见为 X，形成基础包括……；这直接指向 Y 风险。不能仅凭标准无保留意见排除风险，仍需看关键审计事项。”

## 模式 12：控制权变更/治理冲突

**报表信号**

- 股权结构变化、实际控制人变更；
- 董事会/股东大会僵局、议案被否；
- 核心管理人员离职；
- 战略/业务突然调整、资产处置/并购频繁。

**可能解释**

- 新控制人带来新战略/资源；
- 股东内斗导致经营停滞；
- 控制权不稳影响融资、客户、员工。

**核查**

- 股权结构、一致行动人、董事会席位；
- 股东大会/董事会决议；
- 监管关注/诉讼；
- 核心人员、客户/供应商稳定性。

**结论表述**

“20XX 年控制权/管理层发生……变化；短期可能带来战略调整或经营波动。需观察融资、客户、核心团队和重大投资是否受影响。”

## 使用方式

1. 先用 `analyze_statements.py` 的 `signals` 找到可疑区域。
2. 在本文件中匹配模式，形成 2~3 个竞争性假设。
3. 按“核查”列查阅附注/公告/审计意见。
4. 在报告中写“支持证据 + 反向证据 + 待核实”，不要直接下“造假/暴雷”结论。
