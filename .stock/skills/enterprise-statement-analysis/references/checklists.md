# 分析检查清单

用于完整分析、风险核查和报告前的质量检查。逐项打勾，找不到的写进 `待核实事项`，不要用猜测补齐。

## 1. 开始前

- [ ] 明确企业、报告期间、币种/单位、合并/母公司口径。
- [ ] 明确分析目的：投资决策辅助、信用评估、并购、管理层诊断、学术/学习。
- [ ] 取得经审计年报；记录审计意见类型、审计机构、关键审计事项。
- [ ] 记录会计政策变更、重述、并购/处置、合并范围变化、季节性。
- [ ] 至少准备 3~5 年数据；结构分析优先用年度数据。
- [ ] 区分事实、推断、假设；报告里分别标注。

## 2. 三表勾稽与一致性

- [ ] 资产 = 负债 + 股东权益；合并报表与母公司报表的资产总计差异能否解释？
- [ ] 现金流量表“现金及现金等价物净增加额”与资产负债表货币资金变化是否匹配？差异是否来自受限资金/汇率？
- [ ] 净利润与未分配利润、盈余公积的变化是否勾稽？分红、提取盈余公积是否合理？
- [ ] 营业收入、应收账款、合同资产、预收/合同负债的变化是否协调？
- [ ] 营业成本、存货、应付账款/应付票据的变化是否协调？
- [ ] 核心利润与经营活动现金流是否协调？差额去了哪些资产？
- [ ] 资本开支、在建工程、固定资产、无形资产的变化是否协调？
- [ ] 投资支付的现金、长期股权投资、商誉、投资收益的变化是否协调？
- [ ] 借款、利息费用、货币资金、财务费用的变化是否协调？
- [ ] 母公司投资收益与合并投资收益的差异，是否能用子公司分红解释？
- [ ] 少数股东权益、少数股东损益与子公司盈利是否协调？

## 3. 资产质量

### 3.1 货币资金

- [ ] 货币资金规模与日常周转、资本开支、融资环境是否匹配？
- [ ] 是否存在受限资金（保证金、冻结、募集资金专户、存放境外）？
- [ ] 利息收入与平均货币资金规模是否匹配？是否存在“存贷双高”？
- [ ] 货币资金/短期有息负债是否异常高？融资的必要性是什么？

### 3.2 商业债权

- [ ] 应收账款/合同资产的账龄、坏账准备、核销政策。
- [ ] 前五大客户及集中度；是否有关联方。
- [ ] 应收增速与收入增速的差距；是否放宽信用政策。
- [ ] 应收票据/应收款项融资的构成（银行承兑/商业承兑）。
- [ ] 合同资产与项目进度、结算条件是否匹配。
- [ ] 坏账准备是否充足？是否通过少提坏账调节利润？

### 3.3 其他应收款

- [ ] 对象是谁？控股股东、关联方、子公司、员工、保证金？
- [ ] 账龄、坏账准备、是否长期挂账。
- [ ] 是否与“其他应付款”对冲？是否形成资金占用？
- [ ] 是否有违规担保、诉讼、监管处罚？
- [ ] 母公司其他应收款与合并数的差额，是否是对子公司的资金支持？

### 3.4 存货

- [ ] 存货构成（原材料、在产品、产成品、开发成本、合同履约成本）。
- [ ] 库龄、保质期、跌价准备；是否存在积压/滞销。
- [ ] 存货周转率与毛利率的联动；是否“降价也卖不动”。
- [ ] 存货增长与收入/订单/产能是否匹配。
- [ ] 是否通过少转成本、存货积压调节毛利？

### 3.5 固定资产、在建工程、无形资产

- [ ] 固定资产原值/净值、折旧政策、成新率、产能利用率。
- [ ] 固定资产周转率是否用原值？与存货/业务规模是否匹配。
- [ ] 在建工程进度、预算、转固时间；是否长期不转固？
- [ ] 资本开支/经营现金流；扩张是否依赖融资？
- [ ] 无形资产构成、摊销政策、研发资本化率。
- [ ] 是否存在闲置/低效资产？是否应计提减值？

### 3.6 商誉与投资资产

- [ ] 商誉所在资产组、并购标的、业绩承诺完成情况。
- [ ] 减值测试关键假设（收入增长率、毛利率、折现率）。
- [ ] 商誉/净资产、商誉/总资产；是否过高？
- [ ] 长期股权投资明细、权益法/成本法、投资收益与现金分红。
- [ ] 交易性金融资产/其他非流动金融资产的公允价值来源。
- [ ] 投资性房地产的估值模式（成本/公允价值）。

## 4. 负债与资本结构

- [ ] 区分经营性负债、金融性负债、股东入资、留存利润。
- [ ] 有息负债规模、期限、利率、担保、到期分布。
- [ ] 资产负债率 vs 金融性负债率；预收/合同负债的影响。
- [ ] 利息保障倍数、经营现金流对利息/本金的覆盖。
- [ ] 是否存在过度融资、资金闲置、借新还旧？
- [ ] 对外担保、或有负债、诉讼、承诺事项。
- [ ] 少数股东权益/损益的规模与变化；子公司是否存在少数股东搭便车/亏损分担。
- [ ] 股权结构、实际控制人、控制权变更、治理冲突。

## 5. 利润质量

- [ ] 三个净利润（母公司、合并、归母）分别是多少？差异说明什么？
- [ ] 毛利率、核心利润率、净利率的趋势；与同业比较。
- [ ] 核心利润的计算口径是否一致？利息费用如何处理？
- [ ] 营业利润“三支柱两减值”各占多少？残差多大？
- [ ] 其他收益（政府补贴）是否可持续？是否与经营相关？
- [ ] 杂项收益（利息、投资、公允价值变动）是否可持续？公允价值变动是否有现金流？
- [ ] 资产处置收益是否一次性？
- [ ] 资产/信用减值损失是否异常？是否集中计提/少提？
- [ ] 收入确认政策、关联交易、前五大客户、分部报告。
- [ ] 费用率变化是效率提升还是投入不足？研发是否转化为毛利率？
- [ ] 非经常性损益、股权激励、可转债/稀释。

## 6. 现金流质量

- [ ] 经营活动现金流净额与核心利润+其他收益的匹配；获现率。
- [ ] 经营现金流是否覆盖折旧摊销、利息、股利、扩大再生产？
- [ ] 销售回款/采购付款与收入/成本是否匹配？
- [ ] 巨额其他应收款是否干扰经营现金流？
- [ ] 投资活动流出结构：对内 capex vs 对外投资 vs 并购。
- [ ] 投资流出靠什么补偿？未来经营现金流/投资回报/退出安排。
- [ ] 筹资活动流入来源：股东入资、借款、发债；支持了什么？
- [ ] 筹资流出：还本、付息、分红；是否依赖借新还旧？
- [ ] 现金及现金等价物净增加额与货币资金变化是否勾稽？

## 7. 母公司 vs 合并报表

- [ ] 母公司资产结构（经营资产/投资资产）与战略。
- [ ] 控制性投资占用资源、扩张效应、扩张倍数。
- [ ] 母公司净利润 vs 合并净利润 vs 归母净利润。
- [ ] 母公司投资收益 vs 合并投资收益；子公司分红。
- [ ] 母公司其他应收款/预付款项 vs 合并数；资金支持/占用。
- [ ] 母公司有息负债 vs 合并有息负债；集团资金管理。
- [ ] 母公司分红能力 vs 合并偿债能力；不要混用。

## 8. 审计报告与附注

- [ ] 审计意见类型；强调事项段/保留事项/无法表示意见的基础。
- [ ] 关键审计事项：收入确认、应收账款、存货、商誉、关联方、持续经营。
- [ ] 会计政策/会计估计变更；重述。
- [ ] 关联方及关联交易；资金占用、担保、购销、租赁。
- [ ] 或有事项、承诺事项、诉讼、监管处罚。
- [ ] 分部报告：产品/地区/业务板块的收入、利润、资产。
- [ ] 政府补助明细；是否与资产/收益相关。
- [ ] 受限资产、质押/抵押、募集资金使用。
- [ ] 期后事项；持续经营重大不确定性。

## 9. 治理与外部环境

- [ ] 股权结构、实际控制人、董事会/管理层稳定性。
- [ ] 控制权变更、股东内斗、监管关注。
- [ ] 核心人员依赖、组织文化惯性。
- [ ] 行业竞争格局、技术替代、政策/环保/贸易/汇率。
- [ ] 上下游关系惯性；客户/供应商集中度。
- [ ] 核心业务/单一产品/单一地区依赖。

## 10. 前景与反证

- [ ] 经营路径：收入增长需要多少资产/营运资本/资本开支？
- [ ] 投资路径：控制性投资/子公司的盈利、现金流、分红能力。
- [ ] 融资/重组路径：增量贷款、债转股、股东入资、控制权变更、资产置换的条件和代价。
- [ ] 基准/乐观/谨慎情景的关键假设。
- [ ] 每个判断的反向证据和失效条件。
- [ ] 哪些数据一旦出现，会推翻当前结论？

## 11. 报告前自检

- [ ] 事实、推断、假设是否分开表述？
- [ ] 每个关键结论是否有报表/附注依据？
- [ ] 是否把比率当结论？是否使用了不适用行业的阈值？
- [ ] 是否混淆母公司/合并、营业利润/核心利润、净利润/经营现金流？
- [ ] 是否遗漏数据缺口？是否用猜测补齐？
- [ ] 是否给出个性化买卖指令/目标价？应删除。
- [ ] 是否注明数据截止期、币种/单位、审计情况？
- [ ] 是否包含免责声明？
