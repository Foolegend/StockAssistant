**控制性投资分析至少需要**：

- 母公司：长期股权投资、其他应收款、预付款项、其他流动资产、一年内到期的非流动资产、其他非流动资产、资产总计。
- 合并：同一组项目、资产总计。
- 母公司利润表：营业收入、营业成本、税金及附加、销售/管理/研发费用、利息费用、投资收益、净利润。
- 母公司现金流量表：经营现金流（可选，用于分红能力判断）。

## 4. 从年报抄录的步骤

1. 打开年报“母公司资产负债表”，抄录资产总计、长期股权投资、其他应收款、预付款项、其他流动资产、一年内到期的非流动资产、其他非流动资产、负债合计、所有者权益合计、实收资本/股本、资本公积、盈余公积、未分配利润。
2. 打开“合并资产负债表”，抄录同一组项目（用于计算差额）。
3. 打开“母公司利润表”，抄录营业收入、营业成本、税金及附加、销售费用、管理费用、研发费用、利息费用、其他收益、投资收益、净利润。
4. 打开“母公司现金流量表”，抄录经营活动现金流量净额、购建长期资产支付的现金、分配股利/利润或偿付利息支付的现金（可选）。
5. 按上面的 JSON 结构写入 `.tmp/<code>-parent.json`，再运行：
   ```bash
   "%PYTHON_EXEC%" .../fetch_statements.py --code 600519 --years 6 --parent .tmp/600519-parent.json --out .tmp/600519-with-parent.json
   "%PYTHON_EXEC%" .../analyze_statements.py --input .tmp/600519-with-parent.json
   ```
6. 如果只做一次性分析，也可以直接把 `parent_statements` 合并进已有的 statements JSON，再运行 analyze。

## 5. 数据质量检查

运行 analyze 后，先看：

- `meta.is_financial`：金融行业需改用行业指标。
- `data_gaps`：缺哪些数据、影响什么结论。
- `warnings`（fetch 输出）：哪些报表/期间获取失败。
- `periods` 是否连续；是否有重述/缺失年份。
- `parent_analysis` 是否为 null；如果是，控制性投资结论不能下。
- `signals` 是否有证据；不要只看等级。

## 6. 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 把“营业总收入”当“营业收入”算核心利润 | 核心利润虚高/口径不一致 | 用利润表“营业收入”；营业总收入只用于参考 |
| 把“净利润”当经营现金流 | 利润质量误判 | 用经营活动现金流量净额；区分投资/筹资现金流 |
| 用合并报表算母公司控制性投资 | 结论错误 | 用母公司报表与合并报表的差额 |
| 把预收/合同负债当有息负债 | 财务风险高估 | 区分经营性负债与金融性负债 |
| 用固定资产净值算周转率 | 周转率虚高 | 用原值（附注） |
| 缺数据时用 0 或猜测 | 结论不可靠 | 写 null，列入 data_gaps/待核实 |
| 把减值损失的正负号搞反 | 利润结构错误 | 统一为正数损失额；看报表列示方向 |
| 把金融企业套用通用八看 | 指标失真 | 改用行业专用指标，通用框架仅辅助 |
