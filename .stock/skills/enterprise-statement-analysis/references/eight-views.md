## §0 三表关系与读表顺序

### 0.1 三张报表各自回答什么

| 报表 | 一句话 | 它回答的问题 | 常见误读 |
|---|---|---|---|
| 资产负债表 | 实力/底子 | 企业拥有什么资源、欠谁的钱、股东投入和积累了多少？ | 把资产规模当实力，把高负债一律当风险 |
| 利润表 | 能力/面子/结果 | 期间内靠什么赚钱、赚了多少、利润由谁贡献？ | 把净利润当现金，把营业利润当经营利润 |
| 现金流量表 | 活力/日子 | 钱从哪里来、花到哪里去、经营能否自我造血？ | 只看经营现金流净额，不看投资流出和筹资用途 |

### 0.2 三表勾稽

- 现金流量表的“现金及现金等价物净增加额”解释资产负债表中货币资金的变化（需排除受限资金、汇率影响等）。
- 利润表的净利润经过分配后进入资产负债表“盈余公积”和“未分配利润”；其他综合收益进入权益的其他项目。
- 资产负债表是时点表，利润表和现金流量表是期间表；跨期比较时必须保持口径一致。

### 0.3 读表顺序

1. **先看资产负债表右边**：钱从哪里来（经营性负债、金融性负债、股东入资、留存利润），判断资本引入战略和治理立场。
2. **再看左边**：钱变成了什么（经营资产、投资资产、货币资金），判断资源配置战略。
3. **再看利润表**：这些资源产生了什么（核心利润、其他收益、杂项收益、减值）。
4. **最后看现金流量表**：利润和资产变化是否带来现金，投资流出靠什么补偿，筹资流入支持了什么。
5. **回到附注和审计报告**：验证科目构成、关联方、减值假设、受限资金、或有事项。

## §1 看战略

战略不是管理层在“致股东信”里说了什么，而是资产负债表上的资源分配和资金来源所显示的选择。

### 1.1 表内资源与表外资源

- **表内资源**：货币资金、债权、存货、固定资产、无形资产、投资资产等可以用货币计量的资源。
- **表外资源**：股权结构、实际控制人、治理安排、市场与渠道、技术、品牌、人才、股东的社会资源、行业准入、政策关系等。
- 表外资源往往决定表内资源的使用效率。分析时至少问：谁控制企业？股东能带来什么？企业的核心竞争力是否在报表之外？

### 1.2 资产按“对利润的贡献方式”分类

传统按流动性分类（流动/非流动）不直接反映战略。战略视角下，把母公司资产分为：

| 类别 | 典型项目 | 利润贡献方式 |
|---|---|---|
| 经营资产 | 货币资金（小规模时）、应收票据、应收账款、应收款项融资、合同资产、预付款项、存货、固定资产、在建工程、无形资产、开发支出、商誉、长期待摊费用、使用权资产等 | 通过营业收入带来核心利润，再带来经营现金流 |
| 投资资产 | 交易性金融资产、衍生金融资产、债权投资、其他债权投资、长期股权投资、其他权益工具投资、其他非流动金融资产、投资性房地产，以及母公司向子公司提供的其他应收款/预付款项等 | 利息、股利、转让价差、权益法投资收益、公允价值变动；控制性投资还通过子公司经营产生利润 |

**关键口径**：

- 判断资产结构类型，以**母公司资产负债表**为基础；合并报表中控制性投资已被还原为子公司的经营资产，合并报表通常以经营资产为主体。
- 货币资金本身没有战略色彩：规模小时归入经营资产；规模很大、经营现金流充沛时，归入非经营资产更合理，否则会误导结构分析。
- 母公司向子公司提供的资金，可能藏在“其他应收款”“预付款项”“其他流动资产”“一年内到期的非流动资产”“其他非流动资产”中，不能只看“长期股权投资”。

**三种资产结构类型**（剔除货币资金后）：

1. **经营主导型**：经营资产为主。战略含义是聚焦产品/服务、竞争战略和职能战略；风险是行业和核心产品依赖。
2. **投资主导型**：投资资产为主。战略含义是通过控制性投资实现多元化/地区布局/跨越式发展；风险是子公司质量、商誉、投资回报和集团管理。
3. **经营与投资并重型**：两者相当。战略含义是“保持核心业务 + 对外扩张”；风险是资源分散、管理复杂度。

### 1.3 控制性投资与扩张效应（重点）

**控制性投资占用资源**的近似计算（合并数小于母公司数的差额）：

```
控制性投资 ≈ Σ max(母公司项目 − 合并报表项目, 0)
项目包括：长期股权投资、其他应收款、预付款项、其他流动资产、
          一年内到期的非流动资产、其他非流动资产
```

- 只用差额，是因为合并报表已抵销母子公司内部交易；差额反映母公司向子公司提供的、除股权投资以外的资金支持。
- 若合并数大于母公司数（例如预付款项“越合并越大”），说明母公司没有通过该项目向子公司提供资金，不应计入。
- 这是“基本规模”，不是账簿级的精确数；报告中要说明估算性质。

**扩张效应**：

```
控制性投资增量撬动的资源 = 合并资产总计 − 母公司资产总计
扩张倍数 = 控制性投资增量撬动的资源 ÷ 控制性投资占用资源
```

- 扩张效应大，说明母公司以较少资源控制了较大规模的子公司资产；但扩张效应本身不等于效益，还要看子公司的核心利润、经营现金流和资产质量。
- 扩张效应的来源：子公司吸收少数股东入资、子公司贷款、子公司占用上下游商业信用、子公司利润积累。
- 若控制性投资不是为了扩张，而是为了业务整合或提高盈利能力，扩张倍数可能不高；此时应重点看合并利润表与母公司利润表的盈利能力差异。

**常见误判**：

- 只看长期股权投资，忽略其他应收款/预付款项通道。
- 把合并资产减母公司资产直接当成“母公司投资”，没有扣除母公司自身资产变化。
- 把高商誉当成“控制性投资”全部计入；商誉是并购对价超过被并购方可辨认净资产公允价值的差额，是“纸面资产”，不直接推动营业收入。

### 1.4 资本引入战略（资产负债表右边）

把负债和股东权益按来源分为四类：

| 来源 | 典型项目 | 战略含义 |
|---|---|---|
| 经营性负债 | 应付票据、应付账款、预收款项、合同负债（应付职工薪酬、应交税费也属经营性，但分析时通常简化） | 利用上下游商业信用；“两头吃”能力；成本低、偿还压力可能低于账面 |
| 金融性负债 | 短期借款、交易性金融负债、一年内到期的非流动负债、长期借款、应付债券、租赁负债、具有融资性质的长期应付款 | 债务融资驱动；有资本成本和还本付息压力 |
| 股东入资 | 股本/实收资本、资本公积（股东入资部分） | 初始战略、股权结构、治理、资本规模 |
| 留存利润 | 盈余公积、未分配利润 | 利润积累和股利政策；等同于股东再投资 |

**五种资本引入类型**：经营驱动型、债务融资驱动型、股东驱动型、利润驱动型、并重驱动型。类型不是好坏标签，而是判断企业处于什么发展阶段、依赖什么资源。

**“四度”分析**（分母为资产总额或负债与股东权益合计）：

```
商业债务依存度 = 经营性负债 / 资产总额
金融债务依存度 = 金融性负债 / 资产总额
股东贡献度     = (股本 + 资本公积) / 资产总额
利润积累度     = (盈余公积 + 未分配利润) / 资产总额
```

**关键提醒**：

- 高经营性负债可能是竞争优势（占用上下游资金），也可能是经营困难、拖欠货款；要结合应付/预收的动态、存货和现金流判断。
- 预收款项/合同负债包含毛利，实际偿债压力低于账面；高负债率不一定高风险。
- 真正的财务风险主要看**金融性负债率**和有息负债的还本付息安排。

### 1.5 立场：全体股东 vs 控股股东

- 站在全体股东立场：资产结构应系统优化；不能有长期闲置、不能发挥效用的不良资产；资产变化应朝盈利方向。
- 站在控股股东立场：可能出现控股股东利用上市公司资源服务自身战略的情况。
- 典型信号：
  - 其他应收款长期高企，资金流向控股股东/关联方；
  - 上市公司为控股股东/关联方提供违规担保；
  - 高溢价并购控股股东资产；
  - 大额预付款项流向关联方；
  - 货币资金被占用、存贷双高。
- 结论措辞：区分“资金占用嫌疑”“已披露的关联交易”“监管处罚/审计意见确认的事实”，不要混为一谈。

### 1.6 集团管理

母公司对子公司的管理方式会影响合并报表：

| 管理领域 | 观察点 |
|---|---|
| 债务筹资 | 母公司借款、子公司借款、集团统借统还、担保 |
| 货币资金 | 资金集中管理、内部资金拆借、受限资金 |
| 业务关系 | 母子公司购销、内部交易抵销、转移定价 |
| 销售活动 | 销售政策、渠道、关联方销售 |
| 管理费用 | 总部与子公司费用分担、人员薪酬政策 |
| 研发活动 | 研发集中在母公司还是子公司、研发费用归集 |

分析要点：母公司报表和合并报表的差异，往往就是集团管理的痕迹。例如母公司投资收益远高于合并投资收益，可能是子公司分红；母公司其他应收款远高于合并数，可能是向子公司提供资金。

### 1.7 战略维度追问清单

- 资产结构属于经营主导、投资主导还是并重？依据是什么？
- 控制性投资占用多少资源？撬动了多少资产？扩张倍数多少？子公司靠什么扩张？
- 资本引入主要靠经营负债、金融负债、股东入资还是利润积累？是否与发展阶段匹配？
- 是否存在控股股东占款、违规担保、关联交易依赖？
- 母公司报表与合并报表的差异说明了什么集团管理特征？

## §2 看经营资产管理与竞争力

经营资产的管理质量，最终表现为**核心利润**和**经营活动现金流**。不要只看资产周转率，要看资产与业务、竞争力、现金流的匹配。

### 2.1 货币资金

- 货币资金的用途：资本性支出、日常周转、融资环境缓冲。
- 资本性支出由战略决定，通常不能靠经营现金流完全支持，需要另行融资安排。
- 日常周转资金取决于管理能力和竞争力；核心竞争力强的企业可以在较低现金存量下运转。
- 融资环境好、融资能力强，也可以保持较低现金存量。
- **不要简单说“现金越多越好”**：现金过多可能意味着投资机会不足、战略困惑、资金闲置或代理问题；同时要核查受限资金。

### 2.2 以存货为核心的上下游关系管理

营运资本 = 流动资产 − 流动负债；其核心是采购付款、销售回款、短期借款和其他应收款四项安排。

| 环节 | 重点科目 | 观察 |
|---|---|---|
| 采购付款 | 预付款项、应付票据、应付账款 | 预付增加可能表示对供应商议价能力弱或通过预付款向关联方提供资金；应付增加可能是商业信用强，也可能是拖欠 |
| 销售回款 | 应收票据、应收账款、应收款项融资、合同资产、预收款项/合同负债 | 应收增加而收入不增，可能是放宽信用或提前确认收入；预收/合同负债增加可能是产品紧俏或渠道压货 |
| 短期融资 | 短期借款、一年内到期的非流动负债 | 用于弥补营运资金缺口还是过度融资？ |
| 其他应收款 | 其他应收款 | 关联方占款、保证金、备用金；金额大且长期挂账要重点核查 |

**“两头吃”能力**：同时占用上游供应商资金（应付/应付票据）和下游客户资金（预收/合同负债），说明产业链地位强。但要注意：应付长期高企也可能是支付困难。

### 2.3 存货

- 关注规模、结构、周转、毛利率的联动，而不是只看存货多少。
- 存货周转率 = 营业成本 / 平均存货；周转天数 = 365 / 周转率。
- 经验参考：存货周转超过 2 次/年时，核心利润获现率的 1.2~1.5 倍经验值较适用；低于 2 次时要按经营周期判断。
- **异常组合**：毛利率下降 + 存货周转下降 = 降价也卖不动，可能产品被淘汰；毛利率上升 + 存货大增 = 可能通过存货积压/少转成本调节利润。
- 行业例外：白酒陈化、房地产项目周期、船舶/航空长周期、工程在建等，低周转可能是正常商业模式，不能机械套用。

### 2.4 固定资产

- 固定资产周转率 = 营业收入 / 平均固定资产**原值**。书中特别强调用原值，不用净值：净值随折旧递减，会系统性抬高周转率，甚至净值趋零时周转率无穷大。
- 关注固定资产的规模、结构、技术装备水平与存货/业务规模的匹配。
- 固定资产一次性增加过多，可能形成产能闲置；在建工程长期不转固，可能延迟折旧、掩盖产能问题。
- 关注在建工程/固定资产比例、转固时间、资本开支/经营现金流、产能利用率（年报/公告）。

### 2.5 无形资产与研发

- 账面无形资产通常只包括外部购入部分；自创无形资产大量在表外，导致账面无形资产规模低估。
- 研发费用的有效性，不能只看研发费用率；要结合毛利率、产品结构、研发人员、专利和商业化。
- 研发驱动型企业：持续高效研发应支持较高毛利率；研发费用增长但毛利率下降，要追问研发是否成功。
- 商誉不是无形资产，但常与并购的无形资产评估增值一起形成“纸面资产”；它们不直接推动营业收入，却会通过摊销/减值压低未来利润。

### 2.6 资源管理的综合效应

- 总资产报酬率（息税前利润 / 平均总资产）和净资产收益率（净利润 / 平均净资产）用于考察综合效应，但会被资本结构、非经常性损益和会计估计影响。
- 高商誉并购：商誉 = 并购对价 − 被并购方可辨认净资产公允价值。高商誉意味着买方高预期、卖方高业绩对赌，也可能是高估值风险；要结合业绩承诺完成情况、减值测试假设。
- 分析时把“经营资产报酬率”和“非经营资产报酬率”分开看，比单看 ROA 更有信息量（见 §3.4）。

### 2.7 经营资产维度追问清单

- 现金存量与日常周转、资本开支、融资环境是否匹配？是否存在受限资金？
- 应收、存货、应付、预收的动态关系说明了什么？是竞争力还是压力？
- 存货周转与毛利率是否同向？是否出现“降价也卖不动”？
- 固定资产周转用原值还是净值？在建工程是否长期不转固？
- 研发投入是否转化为毛利率和产品竞争力？
- 商誉和并购形成的无形资产是否在支撑收入，还是只是“纸面资产”？

## §3 看效益和质量

### 3.1 三个净利润

| 指标 | 含义 | 用途 |
|---|---|---|
| 母公司净利润 | 上市主体自身经营 + 子公司分红/投资收益 | 分红能力的首要基础；分红时通常取“母公司净利润”与“归母净利润”较低者 |
| 合并净利润 | 整个集团（母 + 子）的盈利能力 | 判断集团整体经营成果 |
| 归属于母公司所有者的净利润 | 合并净利润中属于母公司股东的部分 | 每股收益、市盈率、估值；分红基础之一 |

三者差异是信息：母公司净利润高、合并净利润低，可能子公司亏损或少数股东分走利润；母公司投资收益高、合并投资收益低，可能是子公司向母公司分红。

### 3.2 利润的层次

```
毛利 = 营业收入 − 营业成本
核心利润 = 营业收入 − 营业成本 − 税金及附加 − 销售费用 − 管理费用 − 研发费用 − 利息费用
营业利润 = 核心利润 + 其他收益 + 杂项收益 + 资产处置收益 − 资产减值损失 − 信用减值损失 + 其他项目
利润总额 = 营业利润 + 营业外收入 − 营业外支出
净利润 = 利润总额 − 所得税费用
```

- **核心利润**是经营活动带来的利润，是分析经营竞争力的核心；不要用营业利润率或销售净利率代替核心利润率。
- 核心利润率 = 核心利润 / 营业收入。
- 利息费用与经营活动的关系：若经营现金流长期为正，利息费用主要与融资安排有关；若经营现金流不足、靠借款维持周转，利息费用与经营活动有关。书中为简化，核心利润直接减利息费用。
- 金融企业不适用上述核心利润公式，应使用净利息收入、手续费及佣金净收入等行业口径。

### 3.3 营业收入的质量

从三个问题看：

1. **卖什么**：产品/服务结构、竞争优势、持续性；是否过度依赖单一产品；收入增长是靠自建、并购还是关联交易。
2. **卖给谁/哪个地区**：地区经济后劲、政治经济环境、国际环境；内销/外销的规模和毛利率差异。
3. **靠什么**：靠政府、靠关联方还是靠市场。关联交易可以正常，但比重过大、价格异常、可反市场“制造”业务时要警惕。

结合分部报告、前五大客户、关联交易公告、并购公告，判断收入增长的“含金量”。

### 3.4 费用的质量

- 费用是为实现收入而发生的资源消耗；资产和费用在一定条件下可以相互转化（资本化/费用化），因此费用分析要结合资产。
- 不要片面强调“降费”：研发、品牌、人力资源等费用可能决定未来竞争力；要看费用发生后的效用。
- 费用率要结合业务模式、规模、组织结构、控制权变化；母公司费用率在集团管理下可能没有意义，合并报表费用率更能说明集团效率。
- 研发费用：关注规模、费用率、资本化率、研发人员、专利、毛利率的联动。

### 3.5 利润的结构质量：“三支柱两减值”

营业利润可以拆成：

| 支柱/减项 | 内容 | 分析含义 |
|---|---|---|
| 核心利润 | 营业收入带来的经营利润 | 产品/服务竞争力的核心；应为营业利润的主体 |
| 其他收益 | 政府补贴为主 | 可能持续（符合政策、持续申请），也可能一次性；占比高说明利润依赖补贴 |
| 杂项收益 | 利息收入 + 投资收益 + 公允价值变动收益 | 与非经营资产相关；公允价值变动最“虚”，没有现金流跟进 |
| 资产减值损失 | 存货、固定资产、无形资产、商誉等减值 | 可能是正常质量下降，也可能是利润调节（集中计提/少提） |
| 信用减值损失 | 债权减值（债务人信用恶化） | 与应收账款、其他应收款质量相关；可能滞后于业务发生 |

**残差**：核心利润 + 其他收益 + 杂项收益 + 资产处置收益 − 两项减值，通常不等于营业利润；残差可能来自其他业务利润、未分类项目或数据口径差异。残差过大时要追问。

**资产处置收益**：一次性、不可持续，不应作为持续盈利能力的一部分。

### 3.6 利润结构与资产结构

以合并报表为基础：

```
经营资产 → 营业收入 → 核心利润（+ 与经营相关的其他收益）
非经营资产 → 杂项收益（利息收入、投资收益、公允价值变动收益）

经营资产报酬率 = (核心利润 + 其他收益) / 平均经营资产
非经营资产报酬率 = 杂项收益 / 平均非经营资产
```

- 经营资产报酬率高，通常说明产品/服务有竞争力、经营资产运转效率高。
- 非经营资产报酬率高，说明闲置资金/投资管理能力强；但非经营资产长期占比高、回报低，可能是战略困惑或投资管理弱。
- 经营资产规模大但核心利润占比低，可能是在建工程/固定资产超前、商誉/无形资产评估增值过高、经营资产与业务结构失衡。
- 资产结构分析要与战略（§1）和风险（§7）联动。

### 3.7 利润结构与现金流结构

- 核心利润应带来经营现金流；经验参考：存货周转 > 2 次/年时，经营现金流净额约为（核心利润 + 其他收益）的 1.2~1.5 倍。
- 为什么要求大于 1：经营现金流还要补偿折旧摊销、支付利息、分红、扩大再生产。
- 存货周转 < 2 次、长周期行业：按经营周期判断，不要机械套用 1.2~1.5。
- 有利润无现金时，利润通常对应应收、合同资产、存货等非现金资产的增加；要查附注原值变化，避免被减值准备掩盖。
- 经营现金流长期入不敷出，可能意味着赊销过度、市场能力弱、采购不能利用商业信用、虚假销售等。

### 3.8 利润结果的质量

- 利润的结果是资产；利润散落在各项资产中。资产质量分析（§6）是利润质量分析的延续。
- 例子：少提折旧、少转成本、资产减值不足、费用资本化，都会让当期利润好看，但把问题留在资产里。
- 因此，利润表分析必须回到资产负债表：应收、存货、固定资产、在建工程、无形资产、商誉、其他应收款的变化，是利润质量的“底稿”。

### 3.9 效益维度追问清单

- 三个净利润分别是多少？差异说明什么？
- 核心利润是多少、核心利润率多少、趋势如何？
- 营业利润的三支柱两减值各占多少？残差多大？
- 收入增长靠什么？产品、地区、客户、关联方、并购各贡献多少？
- 费用率变化是效率提升还是投入不足？研发是否转化为毛利率？
- 利润有没有现金流支持？没有现金的利润去了哪些资产？

## §4 看价值

### 4.1 四种“价值”不是一回事

| 价值 | 含义 | 用途/陷阱 |
|---|---|---|
| 账面净资产 | 资产负债表上的股东权益 | 历史成本为主，可能严重低估表外资源；也可能高估不良资产 |
| 评估值 | 评估机构用成本法/收益法/市场法得出的价值 | 依赖假设和评估师判断；非现金入资时评估增值影响股东利益 |
| 交易价值 | 股权交易双方谈成的价格 | 受控制权、交易条件、博弈、流动性影响 |
| 证券市场价格 | 股票市场价格 | 受市场情绪、流动性、估值倍数影响，不等于企业内在价值 |

### 4.2 股东入资的三重效应

1. **为盈利能力奠定基础**：入资资产应与业务相关，能支持持续盈利；非现金入资的资产质量、估值公允性直接影响未来报酬率。
2. **对潜在债务提供保证**：注册资本不实、非现金资产评估增值过高，会削弱对债权人的保障。
3. **协调股东间利益关系**：非现金入资的估价和折股比例，会影响各股东股权比例和治理地位。

### 4.3 估值方法及适用性

| 方法 | 原理 | 适用 | 局限 |
|---|---|---|---|
| 成本法/重置成本法 | 净资产评估值 = 资产评估值 − 负债评估值 | 表外资源少、初始期/没落期企业 | 忽略表外资源、品牌、技术、人才、客户关系 |
| 收益法/收益现值法 | 未来股东权益现金流折现 | 盈利能力较强、稳定发展期企业 | 依赖未来预测和折现率假设；可操纵 |
| 市盈率法 | 净利润 × 倍数 | 有稳定盈利、可比公司 | 净利润口径、倍数选择、周期波动 |
| 市净率法 | 净资产 × 倍数 | 资产驱动型、金融企业 | 账面净资产质量、商誉/不良资产 |

- 成本法和收益法适用于不同生命周期的企业，结果差异大不一定是评估错误。
- 没有估值假设和可靠数据时，不给出伪精确的企业价值或目标价；可以给估值区间和关键假设。
- 控制权溢价、流动性折价、少数股权折价、交易条件（对赌、分期、担保）都会影响交易价值。

### 4.4 价值维度追问清单

- 用户说的是账面净资产、评估值、交易价还是股价？口径是否明确？
- 评估方法是什么？关键假设（增长率、折现率、可比倍数）是否合理？
- 非现金入资的资产评估增值幅度多大？对股东利益和未来报酬率有何影响？
- 控制权、流动性、对赌和交易条件是否被考虑？
- 是否存在表外资源/表外负债未纳入估值？

## §5 看成本决定机制

成本不只是会计结果，而是治理、决策、管理和核算共同作用的结果。分析成本时，先问“谁决定了成本”，再问“成本高不高”。

### 5.1 外部因素

宏观经济、市场竞争、产业政策、地区环境、原材料价格、汇率、环保/安全监管等。外部因素通常不可控，但可以判断企业是否顺周期、是否有成本转嫁能力。

### 5.2 治理因素

- 股东之间不和谐、控制权争夺，可能导致股东大会/董事会无法正常决策，产生诉讼、停滞、人才流失等成本。
- 控股股东/实际控制人违背全体股东利益占用资源、违规担保，会形成根本性的成本/损失。
- 观察：股权结构、董事会构成、控制权变更、关联交易、监管处罚、审计意见。

### 5.3 决策因素（董事会层面）

- 对外投资布局、子公司技术装备水平、固定资产/无形资产的结构与规模：决定了未来的折旧、摊销、维护和产能成本。
- 人力资源政策，尤其是管理层薪酬和激励机制：决定管理成本和代理成本。
- 产品质量标准与市场定位：决定选料、工艺、研发、售后等成本组合；是战略属性，不只是生产问题。

### 5.4 管理因素（管理层层面）

- 人力资源管理：新员工融入、干部培训、岗位匹配；最大的成本可能不是薪酬，而是把不合适的人放在不合适的位置。
- 预算管理：刚性预算 vs 弹性预算；只关注短期利润目标可能损害长期能力；预算的心理弹性会影响员工行为。
- 日常费用管理：差旅、招待、办公等；技术手段可以降本，但管理目标和员工积极性同样重要。

### 5.5 核算因素

- 生产成本分摊标准（期间、产品、产成品/在产品）没有唯一正确答案；选择受行业惯例和管理目标影响。
- 资产减值准备是会计估计，可能被用于利润调节：利润好的年份集中计提、利润差的年份少提/不提，为未来“轻装前进”做准备。
- 成本是一个范围，不是唯一点；分析成本差异时，要区分规模效应、结构变化、会计估计和管理效率。

### 5.6 成本维度追问清单

- 成本水平由外部环境、治理、决策、管理还是核算主导？
- 固定资产/无形资产投资是否超前？折旧摊销压力多大？
- 人工、研发、销售费用是竞争力投入还是失控？
- 成本分摊和减值估计是否改变了利润的可比性？
- 降本是否以牺牲质量、研发、员工积极性为代价？

## §6 看财务状况质量

### 6.1 资产质量：三个层面

| 层面 | 含义 | 判断标准 |
|---|---|---|
| 整体质量 | 资产整体能否为股东权益的非入资性增值做贡献 | 净利润、其他综合收益的长期增长；资产规模与盈利/现金的匹配 |
| 结构质量 | 经营资产是否系统优化；控制性投资和业务板块的盈利能力 | 固定资产与存货/业务匹配；存货与应收/回款的动态；经营资产规模与核心利润/现金流匹配 |
| 个体质量 | 单项资产是否满足企业的特定需求 | 变现质量（流动资产）、被利用质量（长期经营资产）、组合增值质量 |

**关键观点**：资产质量不是物理质量，而是“满足企业特定需求”的质量。一项资产即使物理上很好，如果闲置、不能产生利润和现金，也是不良资产。

### 6.2 主要资产项目的质量

| 项目 | 质量关注点 | 报表/附注线索 |
|---|---|---|
| 货币资金 | 受限资金、存贷双高、资金集中管理 | 附注“货币资金”受限说明、利息收入与平均现金的匹配 |
| 商业债权 | 回收性、账龄、集中度、坏账准备 | 应收账款账龄、前五大客户、坏账准备政策、合同资产 |
| 其他应收款 | 关联方占用、保证金、备用金、长期挂账 | 附注对象、账龄、坏账准备、关联方交易 |
| 存货 | 周转、结构、跌价准备、积压/短缺 | 存货构成、库龄、跌价准备、毛利率与周转的联动 |
| 流动资产整体 | 变现能力与流动负债的匹配 | 不只是流动比率；看经营负债/金融负债结构 |
| 无形资产 | 账面低估、摊销、减值、研发资本化 | 无形资产构成、研发支出资本化率、摊销政策 |
| 投资资产 | 投资回报、减值、控制性投资质量 | 长期股权投资明细、投资收益、权益法、商誉 |
| 固定资产/在建工程 | 利用率、转固、产能消化、折旧政策 | 原值/净值、在建工程进度、资本开支、产能利用率 |
| 商誉 | 减值风险、业绩承诺、并购协同 | 商誉所在资产组、减值测试假设、业绩承诺完成情况 |

### 6.3 资本结构质量

- 股权结构与企业发展战略的关联度：谁控制企业？股权结构能否支持战略？
- 入资内容的质量：非现金资产的估价、实物形态是否服务业务。
- 负债与推动项目的对应性：贷款推动的项目至少要能达到盈亏平衡，否则还本付息缺乏保障。
- “四度”分析（见 §1.4）：商业债务依存度、金融债务依存度、股东贡献度、利润积累度。
- 降低债务依存度的路径：股东入资、提高利润积累度；后者与现金分红政策相矛盾。

### 6.4 现金流量表分析

**分析起点：投资活动现金流出量的补偿机制。** 钱花出去，靠什么补回来？

| 流出 | 补偿来源 | 判断 |
|---|---|---|
| 购建固定资产、无形资产和其他长期资产 | 未来使用期内经营活动现金流（通过折旧/摊销速度） | 资本开支/经营现金流、在建工程转固、收入/核心利润增长 |
| 投资支付的现金（对外投资） | 未来收回投资、取得投资收益的现金 | 投资回报率、被投资企业质量、退出安排 |
| 取得子公司支付的现金 | 子公司未来经营现金流/分红 | 商誉、业绩承诺、并购后盈利 |

**经营活动现金流量质量**：

- 充分性：与（核心利润 + 其他收益）比较；再与用途比较（折旧摊销、利息、股利、扩大再生产）。
- 正常性：销售回款、采购付款是否与收入/成本匹配；其他应收款是否干扰经营现金流。
- 巨额其他应收款：如果是向子公司提供资金，本质是投资活动；如果是向母公司/兄弟公司提供，是关联方占用；都不属于经营活动。

**投资活动现金流量质量**：

- 看流出结构：对内扩大再生产（购建长期资产）vs 对外扩张（投资支付、并购）。
- 看流出与效益的关系：在建工程/固定资产增加是否带来收入、核心利润、经营现金流；转固时间是否过长。
- 投资活动现金流长期为正（卖资产）不一定是好事，可能意味着收缩。

**筹资活动现金流量质量**：

- 看流入来源和规模：股东入资、借款、发债；筹资支持了什么（经营、投资、还债）。
- 看流出：还本、付息、分红；是否依赖借新还旧。
- 经营现金流充足却持续大量融资，要追问过度融资/资金闲置/代理问题。

### 6.5 母公司报表与合并报表

| 维度 | 母公司报表 | 合并报表 |
|---|---|---|
| 视角 | 上市主体自身 | 整个集团 |
| 控制性投资 | 长期股权投资等 | 已还原为子公司经营资产 |
| 分红能力 | 母公司净利润、可分配利润 | 归母净利润是分红基础之一 |
| 资金管理 | 其他应收款/预付款项可能反映对子公司资金支持 | 内部交易已抵销 |
| 偿债能力 | 母公司自身债务 | 集团整体债务（含子公司） |

**不要用合并报表判断母公司分红能力，也不要用母公司报表判断集团整体经营。**

### 6.6 比率分析的局限

- 流动比率、速动比率、资产负债率、总资产周转率等通用比率，不能单独决定“安全”或“危险”。
- 杜邦分析适合单一经营企业；投资主导型企业、金融企业、控股平台可能不适用。
- 比率要结合多年趋势、同业可比、业务模式、会计政策和附注。
- 不把任何经验阈值当成普适定律；报告里要写“经验参考”和适用条件。

### 6.7 财务状况质量追问清单

- 资产整体是否在为股东权益的非入资性增值做贡献？
- 经营资产结构是否系统优化？有没有长期闲置/不良资产？
- 主要资产项目的变现/利用/组合质量如何？
- 资本结构是否支持战略？债务推动的项目能否盈亏平衡？
- 经营现金流是否充分、正常？投资流出靠什么补偿？筹资流入支持了什么？
- 母公司报表与合并报表的差异说明了什么？

## §7 看风险

### 7.1 经营风险 vs 财务风险

| 风险 | 定义 | 报表线索 |
|---|---|---|
| 经营风险 | 未来经营活动及盈利能力的不确定性 | 资产→核心利润→经营现金流链条；毛利率、存货周转、核心利润率、获现率；上下游依赖、产品/地区集中、关联交易 |
| 财务风险 | 金融债务融资及还本付息的不确定性 | 资产负债率、金融性负债率、利息保障倍数、债务期限结构、担保/或有负债、现金流对债务的覆盖 |

### 7.2 经营风险的报表线索

- 流动资产与流动负债的关系：核心是上下游关系管理和短期融资安排，不是简单的流动比率。
- 毛利率、存货周转率、核心利润率、核心利润获现率的趋势。
- 经营资产→核心利润→经营现金流这条线是否顺畅；子公司是否拖累集团。
- 产品/客户/地区集中度、关联交易依赖、核心业务惯性。
- 外部环境变化：政策、竞争、技术替代、上下游惯性。

### 7.3 财务风险的报表线索

- 资产负债率：经验上超过 70% 财务风险较大，但要区分经营性负债和金融性负债；预收/合同负债多、毛利率高的企业，高负债率可能不可怕。
- 资产金融性负债率 = 金融性负债 / 资产总额；比资产负债率更能反映真实财务风险。
- 利息保障倍数 = (利润总额 + 利息费用) / 利息费用。书中提醒：它更像衡量债务融资效用的指标，不是偿债能力指标；偿债能力要看现金流。
- 核心利润率与融资能力：经营风险低的企业，财务风险通常不会太高；产品没有盈利能力，融资风险会很高。
- 银行贷款的“三品”：人品（治理/管理层行为）、产品（盈利能力）、押品（保障措施）。

### 7.4 利润结构与企业风险

- 营业利润“三支柱两减值”失衡：核心利润弱、补贴/杂项收益/减值贡献大，说明盈利质量差、可持续性弱。
- 利润结构与资产结构反差：经营资产规模大但回报低，或非经营资产规模大但回报低，都是风险区域。
- 子公司盈利能力差异：不同子公司/业务板块的回报差异，可能揭示投资质量差、需要剥离或重组的区域。

### 7.5 过度融资与过度投资

**财务表现**：

1. 负债与股东权益方：金融性负债长期居高不下，股东入资频繁。
2. 资产方：货币资金（融资后闲置）、在建工程、固定资产、无形资产增长过快；固定资产原值增长显著快于营业收入。
3. 并购扩张：高商誉、高无形资产评估增值。
4. 利润表：财务费用长期居高不下。
5. 现金流量表：投资活动现金流出活跃，筹资活动现金流入在逻辑上支持投资流出。

**判断**：企业不是饿死的，可能是撑死的。过度融资导致资金闲置、资产报酬率下降、资产结构失衡；过度投资导致产能过剩、回报不达预期。

### 7.6 治理、控制权与惯性风险

- 股权结构变化、实际控制人变更、核心管理人员更迭：可能导致战略突变、融资中断、重大投资暂停、合作方解约。
- 治理冲突：股东内斗、董事会/股东大会僵局、监管关注。
- 惯性依赖：
  - 上下游关系惯性：上下游经营环境变化，原有商业信用/结算安排失效；
  - 组织文化惯性：过度依赖“企业皇帝”/少数人；
  - 竞争环境惯性：按过去竞争格局做投资/产能决策；
  - 核心业务惯性：过度依赖单一产品/地区，抗变能力差。
- 外部环境：政治、政策、经济周期、技术替代、贸易/汇率、环保/安全。

### 7.7 审计报告与关键审计事项

| 审计意见 | 含义 | 风险提示 |
|---|---|---|
| 标准无保留意见 | 报表在所有重大方面公允反映 | 仍需看关键审计事项 |
| 带强调事项段的无保留意见 | 基本公允，但有需要说明的事项 | 持续经营、重大不确定性、诉讼、资产查封等 |
| 保留意见 | 整体公允，但存在重大错报/范围受限 | 具体保留事项就是风险点 |
| 否定意见 | 报表整体不公允 | 极高风险 |
| 无法表示意见 | 审计范围受限，无法获取充分证据 | 极高风险；常见于资金占用、造假、持续经营问题 |

**关键审计事项**：审计师认为对财务信息质量影响最大的事项，通常就是风险区域（收入确认、应收账款、存货、商誉、关联方、持续经营）。要读“关键审计事项”段落和审计师的应对程序。

### 7.8 风险维度追问清单

- 经营风险和财务风险分别在哪里？是否相互强化？
- 利润结构中哪一根支柱最脆弱？减值是否可能继续？
- 有息负债规模、期限、利率、担保、到期分布如何？经营现金流能否覆盖？
- 是否存在过度融资/过度投资？资金闲置还是资金紧张？
- 治理/控制权/核心人员是否稳定？是否有监管处罚/诉讼？
- 审计意见和关键审计事项说了什么？是否涉及持续经营？

## §8 看前景

### 8.1 基础分析（以资产负债表为核心）

1. **资产总规模及变化**：稳定发展、持续扩张还是持续萎缩？资产重大变化由“四大动力”中的哪一个/几个导致？
2. **经营资产 vs 投资资产**：各占多少？控制性投资规模、扩张效应如何？
3. **主要资产变化及方向**：流动资产、投资资产、固定资产、无形资产分别怎么变？对盈利有何影响？
4. **不良资产区域**：闲置固定资产、潜亏投资、周转缓慢的存货/债权、长期挂账的其他应收款。
5. **流动资产对流动负债的保障**：不计算流动比率；看上下游关系、短期融资、集团资金管理。
6. **负债融资潜力**：重点看金融负债率、盈利能力、现金能力、担保/押品。
7. **母公司 vs 合并报表**：集团管理特征、业务关系、管理效率、战略信息、经营资产竞争力、盈利质量。

### 8.2 三步法预测

| 路径 | 看什么 | 关键假设/验证 |
|---|---|---|
| 经营活动 | 经营资产（债权回收、存货周转、固定资产利用、无形资产）→ 核心利润 → 经营现金流 | 收入增长所需资产/营运资本；毛利率、费用率；现金转化 |
| 投资活动 | 控制性投资/子公司经营资产 → 子公司核心利润/现金流/分红 | 子公司行业前景、竞争地位、资本开支、少数股东；商誉/减值 |
| 融资/重组/并购 | 增量贷款、债转股、股东增量入资、控制权变更、资产置换 | 融资条件、成本、摊薄、控制权、资产估价、整合风险 |

**情景**：基准、乐观、谨慎；每个情景列出关键假设、支持证据、反向证据、可能失效的条件。不要用历史增速机械外推。

### 8.3 发展路径及代价

- **增量贷款**：盈利能力强、负债率低的企业首选；负债率高/盈利弱时取决于担保。
- **债转股**：资不抵债的重组或可转债转股；改善融资能力但摊薄股东。
- **股东增量入资**：现金或非现金（土地使用权、股权等）；非现金入资要关注估价公允性。
- **控制权变更/核心人员变动**：可能带来新战略，也可能带来动荡；取决于原控制股东意愿和交易条件。
- **资产置换**：改变行业和盈利能力；关注置入资产质量、估价、关联交易。

### 8.4 前景维度追问清单

- 企业的大势是扩张、稳定还是收缩？由什么驱动？
- 经营资产能否支持收入/核心利润/现金流增长？需要多少资本开支和营运资本？
- 控制性投资/子公司能否贡献利润和现金？商誉/减值风险多大？
- 融资/重组/并购路径的前提是什么？代价（摊薄、控制权、整合）是什么？
- 哪些条件一旦不成立，当前判断会被推翻？

## §9 综合分析的组织方式

完整分析不是把八看逐项写一遍，而是围绕一条主线：

1. **战略选择**：资产结构 + 资本引入 + 控制性投资 → 企业选择做什么、靠什么做。
2. **经营结果**：经营资产 → 核心利润 → 经营现金流 → 利润质量。
3. **财务结果**：资产质量、资本结构、现金流质量 → 财务状况质量。
4. **风险与前景**：哪些环节最脆弱？未来靠什么路径发展？前提是什么？

写报告时，每个判断都要有“报表依据 + 业务解释 + 不确定性”。不要把比率堆砌成结论，也不要把管理层的战略表述当成事实。
