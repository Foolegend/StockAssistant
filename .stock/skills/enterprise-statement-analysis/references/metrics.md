# 指标、口径与脚本输出

本文件说明脚本用到的公式、分类口径、经验阈值的边界，以及如何把年报科目对应到脚本字段。做分析前先读本文件，避免把不同口径混在一起。

## 1. 数据口径

- 默认使用**合并报表**、**年度报告**、人民币元；脚本输出的金额单位是**亿元**（除以 1e8），比率是百分数（除特别注明外）。
- 平均余额 = (期初 + 期末) / 2。第一期没有上期数据时，脚本用期末数代替，并在 `data_gaps` 中提示。
- 数据源为东方财富 F10 年报数据时，可能与企业年报 PDF 存在重述、四舍五入、科目重分类差异；最终以年报及附注为准。
- 金融企业（银行/保险/证券）使用专用报表模板；核心利润、经营资产分类、存货周转等通用指标不适用，脚本会标记 `is_financial`。

## 2. 核心公式

### 2.1 利润表

```
毛利 = 营业收入 − 营业成本
毛利率 = 毛利 / 营业收入 × 100%

核心利润 = 营业收入 − 营业成本 − 税金及附加
           − 销售费用 − 管理费用 − 研发费用 − 利息费用
核心利润率 = 核心利润 / 营业收入 × 100%

营业利润 = 核心利润 + 其他收益 + 杂项收益 + 资产处置收益
           − 资产减值损失 − 信用减值损失 + 其他项目
利润总额 = 营业利润 + 营业外收入 − 营业外支出
净利润 = 利润总额 − 所得税费用

杂项收益 = 利息收入 + 投资收益 + 公允价值变动收益
```

**口径注意**：

- `营业收入` 优先用利润表的“营业收入”（`OPERATE_INCOME`），不是“营业总收入”。营业总收入可能包含利息收入、已赚保费、手续费及佣金收入。
- `利息费用` 优先用财务费用明细中的“利息费用”（`FE_INTEREST_EXPENSE`）；金融企业用“利息支出”（`INTEREST_EXPENSE`）。
- 利息收入：优先用营业总收入中的“利息收入”（`INTEREST_INCOME`）；若没有，才用财务费用中的“利息收入”（`FE_INTEREST_INCOME`），后者可能已经影响核心利润的口径，需在报告中说明。
- 资产减值损失/信用减值损失按**净损失**处理：正数表示损失，负数表示转回/收益；信用减值转回会减少总减值负担，不应取绝对值相加。
- 营业利润的“残差” = 营业利润 −（核心利润 + 其他收益 + 杂项收益 + 资产处置收益 − 净减值损失）。残差可能来自其他业务利润、利息收入列示口径、未分类项目或数据差异；残差占营业利润超过 10% 时，脚本会提示核查，不要强行把残差归入某一支柱。

### 2.2 资产分类

**经营资产**（默认）：

```
应收票据、应收账款、应收款项融资、合同资产、预付款项、存货、
固定资产、在建工程、工程物资、生产性生物资产、油气资产、
无形资产、开发支出、商誉、使用权资产、长期待摊费用、
其他流动资产、其他非流动资产、应收补贴款、应收出口退税
```

**非经营资产**（默认）：

```
货币资金、交易性金融资产、衍生金融资产、债权投资、其他债权投资、
长期股权投资、其他权益工具投资、其他非流动金融资产、投资性房地产、
其他应收款、长期应收款、一年内到期的非流动资产、
拆出资金、发放贷款及垫款、存放中央银行款项、存放同业款项、
买入返售金融资产、贵金属、融出资金、应收利息、应收股利、持有待售资产
```

**未分类资产** = 资产总计 − 经营资产 − 非经营资产；通常为递延所得税资产等。未分类占比高时，报告要说明。

**关键口径**：

- 货币资金默认归入非经营资产。理由：货币资金本身不直接产生核心利润；在经营现金流充沛、现金规模大时，归入经营资产会误导结构分析。若现金规模很小，这一归类对比例影响不大。
- 其他应收款默认归入非经营资产，因为大额其他应收款常见于关联方资金占用/资金拆借；若企业其他应收款主要是经营保证金，应在报告中调整说明。
- 商誉归入经营资产，但它不直接推动营业收入；商誉占经营资产比例高时，经营资产报酬率会被拉低，这是有信息量的。
- 战略分析（资产结构类型、控制性投资）以**母公司报表**为基础；合并报表的结构性盈利能力分析以**合并报表**为基础。两者不要混用。

### 2.3 资产报酬率与周转率

```
平均经营资产 = (期初经营资产 + 期末经营资产) / 2
平均非经营资产 = (期初非经营资产 + 期末非经营资产) / 2

经营资产报酬率 = (核心利润 + 其他收益) / 平均经营资产 × 100%
非经营资产报酬率 = 杂项收益 / 平均非经营资产 × 100%
经营资产周转率 = 营业收入 / 平均经营资产
总资产周转率 = 营业收入 / 平均总资产

存货周转率 = 营业成本 / 平均存货
存货周转天数 = 365 / 存货周转率
固定资产周转率 = 营业收入 / 平均固定资产原值
```

**口径注意**：

- 固定资产周转率书中强调用**原值**；脚本只能从公开接口取得净值时，会输出 `fixed_asset_turnover_net` 并在 `data_gaps` 提示。用净值会因折旧而系统性抬高周转率。
- 存货周转率的“营业成本”是利润表营业成本，不是采购额；季节性强的企业用年度数据更稳。
- 经营资产报酬率的分母是经营资产，不是总资产；不要与 ROA 混用。
- 非经营资产报酬率的分母包括货币资金和投资资产；货币资金收益率低会拉低该比率，这是正常的。

### 2.4 资本结构与“四度”

```
商业债务依存度 = 经营性负债 / 资产总额 × 100%
金融债务依存度 = 金融性负债 / 资产总额 × 100%
股东贡献度 = (股本 + 资本公积) / 资产总额 × 100%
利润积累度 = (盈余公积 + 未分配利润) / 资产总额 × 100%

资产负债率 = 负债总额 / 资产总额 × 100%
金融性负债率 = 金融性负债 / 资产总额 × 100%
净负债 = 金融性负债 − 货币资金
净负债率 = 净负债 / 股东权益 × 100%
利息保障倍数 = (利润总额 + 利息费用) / 利息费用
```

**经营性负债**（用于四度）：应付票据、应付账款、预收款项、合同负债。应付职工薪酬、应交税费、其他应付款属于经营性负债，但书中为聚焦分析通常简化；脚本单独输出 `other_operating_liabilities`。

**金融性负债**：短期借款、交易性金融负债、一年内到期的非流动负债、长期借款、应付债券、应付短期债券、租赁负债、具有融资性质的长期应付款、同业存放款项（金融子公司）。应付利息/应付股利若已包含在“其他应付款”中，不重复计入。

**口径注意**：

- 预收款项/合同负债包含毛利，实际偿债压力低于账面；高负债率不一定高风险。
- 资产负债率超过 70% 是经验警戒线，不是定理；必须结合金融性负债率、现金流、行业。
- 利息保障倍数书中认为更像“债务融资效用”指标，不是偿债能力指标；偿债能力要看经营现金流和到期安排。

### 2.5 现金流

```
核心利润获现率 = 经营活动现金流量净额 / (核心利润 + 其他收益)

折旧摊销 = 固定资产折旧、油气资产折耗、生产性生物资产折旧
           + 无形资产摊销 + 长期待摊费用摊销 + 使用权资产摊销

经营现金流对折旧摊销覆盖 = 经营活动现金流量净额 − 折旧摊销
经营现金流对利息覆盖 = 经营活动现金流量净额 − 利息费用
经营现金流对股利/利息覆盖 = 经营活动现金流量净额 − 分配股利、利润或偿付利息支付的现金

自由现金流 = 经营活动现金流量净额 − 购建长期资产支付的现金
资本开支/经营现金流 = 购建长期资产支付的现金 / 经营活动现金流量净额
投资流出/经营现金流 = (购建长期资产 + 对外投资 + 取得子公司) / 经营活动现金流量净额

融资流入 = 吸收投资 + 取得借款 + 发行债券
融资流出 = 偿还债务 + 分配股利、利润或偿付利息
净融资 = 融资流入 − 融资流出
```

**口径注意**：

- 1.2~1.5 倍获现率是经验参考，前提是存货周转 > 2 次/年、经营性非流动资产占比不极端；长周期行业、预收模式、金融子公司会显著改变该比率。
- 经营现金流要能与用途比较：折旧摊销、利息、股利、扩大再生产。仅看“经营现金流 + 投资现金流 > 0”没有意义。
- 巨额其他应收款会干扰经营现金流；如果是向子公司提供资金，本质是投资活动；如果是向母公司/兄弟公司提供，是关联方占用。
- 投资活动现金流长期为正（卖资产）不一定是好事；要区分收缩与优化。

### 2.6 资产质量与风险指标

```
应收/收入 = (应收票据 + 应收账款 + 应收款项融资 + 合同资产) / 营业收入 × 100%
应收增速 − 收入增速 = 应收同比增速 − 营业收入同比增速
存货/营业成本 = 存货 / 营业成本 × 100%
商誉/净资产 = 商誉 / 股东权益 × 100%
商誉/总资产 = 商誉 / 资产总额 × 100%
其他应收款/总资产 = 其他应收款 / 资产总额 × 100%
其他应收款/收入 = 其他应收款 / 营业收入 × 100%
在建工程/固定资产 = 在建工程 / 固定资产 × 100%
货币资金/短期有息负债 = 货币资金 / (短期借款 + 一年内到期非流动负债 + 应付短期债券)

ROE = 归母净利润 / 平均归母股东权益 × 100%
ROA = 净利润 / 平均总资产 × 100%
```

**经验信号（只用于提问）**：

| 信号 | 经验阈值 | 需要追问 |
|---|---|---|
| 核心利润为负 | < 0 | 产品/服务是否还有竞争力？成本结构能否改善？ |
| 核心利润率持续下降 | 连续 2~3 年下降 | 价格战、成本上升、产品老化还是会计估计？ |
| 获现率低 | < 0.8（存货周转 > 2 时） | 应收/存货/预付款增加？收入确认政策？ |
| 应收增速远超收入 | 差距 > 20 个百分点 | 放宽信用、提前确认收入、关联方赊销？ |
| 存货周转低 | < 2 次/年（非长周期行业） | 积压、跌价、少转成本？ |
| 商誉/净资产高 | > 30% | 减值测试、业绩承诺、并购协同？ |
| 其他应收款/总资产高 | > 5% | 关联方占用、资金拆借、坏账准备？ |
| 金融性负债率高 | > 30% | 债务期限、利率、现金流覆盖、过度融资？ |
| 资产负债率高 | > 70% | 是经营负债还是金融负债？预收/合同负债多少？ |
| 利息保障倍数低 | < 2 | 利息费用、利润波动、现金流覆盖？ |
| 资本开支/经营现金流高 | > 1.5 且净融资 > 0 | 扩张是否依赖融资？产能能否消化？ |
| 减值/营业利润高 | > 30% | 正常质量下降还是集中计提调节利润？ |
| 其他收益/营业利润高 | > 30% | 补贴是否可持续？政策依赖？ |
| 杂项收益/营业利润高 | > 30% | 投资收益/公允价值变动是否可持续？ |
| 存贷双高 | 货币资金/短期有息负债 > 3 且有息负债率 > 20% | 受限资金、融资必要性、代理问题？ |

**重要**：阈值不是普适定律；报告里要写“经验参考”“需结合行业/商业模式/附注”，不要用单一阈值下结论。

## 3. 行业适用性

| 行业 | 需要调整的地方 |
|---|---|
| 银行/保险/证券 | 核心利润、经营资产分类、存货周转不适用；改用净息差、不良率、拨备覆盖率、资本充足率、保费/投资收益等 |
| 房地产 | 存货（开发成本/开发产品）周转慢是常态；预收/合同负债多；项目周期、土储、有息负债、现金流覆盖 |
| 建筑/工程 | 合同资产、应收账款、在建工程占比高；按项目周期看现金流；毛利率低、垫资多 |
| 白酒/食品 | 存货陈化/保质期；预收/合同负债；渠道库存；低周转可能是正常 |
| 零售/电商 | 存货周转快；应付账款/合同负债体现产业链地位；毛利率与费用率联动 |
| 重资产/周期 | 固定资产/在建工程大；折旧、产能利用率、资本开支周期；避免用单年周转率下结论 |
| 科技/研发驱动 | 研发费用、资本化率、无形资产、股权激励；表外研发/人才资源 |
| 投资控股/集团 | 以母公司报表看控制性投资、分红能力；以合并报表看集团整体；商誉/长期股权投资质量 |

## 4. 脚本字段速查

### 4.1 fetch_statements.py 输出

```
meta: code, name, industry, market, company_type, is_financial, currency, unit,
      source, fetched_at
periods: ["2025", "2024", ...]（降序）
statements: {
  "2025": {
    "report_date": "2025-12-31",
    "balance": {...},   # total_assets, monetary_funds, inventory, ...
    "income": {...},    # operating_income, operating_cost, core profit 原始科目...
    "cashflow": {...}   # operating_cash_flow, capex, ...
  }
}
parent_statements: null 或 {period: {balance, income, cashflow}}
warnings: [...]
empty_periods: [...]
```

### 4.2 analyze_statements.py 输出

- `metrics.<period>`：`revenue_yi`, `growth`, `profit_structure`, `assets`, `capital`, `cashflow`, `quality`, `data_notes`。
- `latest`：最新期 `metrics` 的副本。
- `parent_analysis`：`periods`, `latest`, `latest_metrics`；`latest_metrics` 含 `controlling_investment_yi`、`expansion_effect_yi`、`expansion_multiple`、母子公司利润/投资收益差异。
- `signals`：`level`（high/medium/info）、`category`、`id`、`message`、`evidence`、`period`。
- `data_gaps`、`caveats`、`questions`、`disclaimer`。

### 4.3 字段命名约定

- 金额：`*_yi` 表示亿元；`*_pct` 表示百分数；`*_turnover` 表示次数；`*_ratio` 表示倍数。
- 缺失：`null`；脚本不会用 0 代替缺失（除非在公式中明确按 0 处理，并写入 `data_gaps`）。
- 符号：减值损失统一为正数损失额；现金流流入为正、流出为负（按报表科目方向）。

## 5. 数据缺口处理

| 缺口 | 影响 | 处理 |
|---|---|---|
| 无母公司报表 | 无法算控制性投资、扩张效应、母公司分红能力 | 从年报母公司报表抄录，按 `data-schema.md` 组装；报告中标注 |
| 无固定资产原值 | 固定资产周转率只能用净值，偏高 | 从附注取得原值；报告中说明 |
| 无折旧摊销 | 无法算经营现金流对折旧摊销的覆盖 | 从现金流量表补充资料取得；或标注缺口 |
| 无应收/存货账龄 | 无法判断回收/跌价风险 | 查阅附注；报告中列为待核实 |
| 金融行业 | 通用指标不适用 | 改用行业指标；通用八看仅作辅助 |
| 季度/半年数据 | 季节性、累计口径 | 结构分析优先用年报；季度只用于趋势更新 |
| 数据源重述 | 跨期不可比 | 使用最新重述数据；报告中说明 |
