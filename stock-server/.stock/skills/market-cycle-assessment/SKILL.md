# 市场周期与晴雨表评估

根据用户提供的市场评估指南，逐项整理市场所处状态。目标是呈现市场环境与情绪信号，不是预测短期涨跌，也不是给出个股买卖建议。

## 开始前

1. 确认评估对象和时点。若用户未说明市场/国家或地区，先询问；若未指定指数，使用该市场的广泛股票市场指标作为观察对象，并说明选择。用户未指定时点则使用当前可获得的最新数据，注明数据截止日期。
2. 查找可核验的近期数据和可靠来源。优先使用央行、统计机构、交易所、基金或行业协会等一手来源；对市场价格、资金流和情绪数据，可使用可信的金融数据来源。不要把过时信息描述成实时数据。
3. 不要因某项数据难以获取而跳过指标或推测数值。标为“暂无可靠数据”，说明缺失原因；可以给出有来源支持的定性判断，但要标明依据和局限。

## 评估指标

必须输出下列所有指标。每项状态应概括当前观察，与指南中的两侧特征进行比较：

| 类别 | 指标 | 偏乐观/宽松的一侧 | 偏悲观/收紧的一侧 |
|---|---|---|---|
| 宏观与资金 | 经济现状 | 生机勃勃 | 停滞不前 |
| 宏观与资金 | 经济展望 | 正面有利 | 负面不利 |
| 宏观与资金 | 贷款机构 | 急于放贷 | 惜贷谨慎 |
| 宏观与资金 | 资本市场 | 宽松 | 紧缩 |
| 宏观与资金 | 资本供给 | 充足 | 短缺 |
| 融资与利率 | 融资条款 | 宽松 | 严格 |
| 融资与利率 | 利率水平 | 低 | 高 |
| 融资与利率 | 利差水平 | 窄 | 宽 |
| 投资者与交易 | 投资人情绪 | 乐观、自信、渴望买进 | 悲观、忧虑、不愿买进 |
| 投资者与交易 | 资产持有人行为 | 乐于持有 | 急于卖出离场 |
| 投资者与交易 | 卖家供给 | 稀少 | 众多 |
| 投资者与交易 | 市场参与状况 | 人群拥挤、参与踊跃 | 乏人问津、参与冷淡 |
| 投资者与交易 | 基金募集与管理人态度 | 申购门槛高、频发新基金、管理人声称有充足资金 | 向所有人开放申购、只有少数优质基金能募资、投资人话语权强 |
| 市场定价与风险 | 近期业绩表现 | 强劲 | 萎靡 |
| 市场定价与风险 | 资产价格 | 高 | 低 |
| 市场定价与风险 | 预期收益 | 低 | 高 |
| 市场定价与风险 | 市场感知风险 | 高 | 低 |
| 投资风格 | 流行风格 | 激进、四处投资 | 审慎自律、精挑细选 |
| 投资风格 | 更适宜的风格 | 审慎自律、精挑细选 | 激进、四处投资 |
| 常见错误 | 易犯错误 | 买进太多、追涨高价、承担过多风险 | 买进太少、离开市场、承担过少风险 |

注意：“市场感知风险”描述投资者对风险的感受，不等同于客观或基本面风险；分别说明两者可能不一致。“更适宜的风格”是指南中的逆向提示，不应表述为无条件适用的操作指令。

## 输出格式

开头注明：

- **评估对象：** 市场/地区及所用指数或代理指标
- **数据截止：** 日期；重要数据各自的发布日期或统计期
- **总体判断：** 偏乐观/偏悲观/中性/信号分化

随后用表格逐项输出全部指标：

| 类别 | 指标 | 当前观察 | 指南方向 | 依据与来源 | 置信度 |
|---|---|---|---|---|---|

“指南方向”统一使用“偏乐观”“偏悲观”“中性/分化”或“暂无可靠数据”。每项“当前观察”尽量给出具体数据、趋势或可验证事实；“依据与来源”提供来源名称、日期和链接（如可用）；“置信度”使用高/中/低，并简述主要限制。若不同来源或子市场信号冲突，标为“中性/分化”，说明冲突，不要强行归类。

表格后简要总结：

1. 哪些指标显示市场情绪或融资环境偏热/偏冷；
2. 哪些关键指标方向相反或数据不足；
3. 这些信号对市场风险和预期收益的含义，以及判断的不确定性。

不要把指标简单相加成未经定义的分数，不要将相关性说成因果关系，不要声称晴雨表能精确择时。明确说明这是基于公开信息的市场环境分析，不构成个性化投资建议。
